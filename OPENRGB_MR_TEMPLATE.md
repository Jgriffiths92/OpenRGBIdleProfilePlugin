## What The Plugin Does

- Switches to a selected idle profile after a configurable inactivity timeout.
- Restores a selected active profile when user input resumes.
- Provides UI options for startup apply, cooldown/debounce, debug logging, and live status.

## Compatibility

- OpenRGB version tested: 1.0rc2wr0 (or update)
- OpenRGB plugin API version: 4
- Platform tested: Windows
- Build/runtime note: built against Qt5 to match Qt5 OpenRGB runtime
